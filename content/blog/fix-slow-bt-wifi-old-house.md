# BT whole home Wi-Fi in an old Buckinghamshire house: why the signal still drops

If you've typed bt internet very slow into Google more than once this month, you're not alone. It's one of the most common complaints on BT's own community forum, and a lot of the threads have one thing in common: an older house with thick walls.

Here's the honest version of what's going on, and what actually fixes it.

[See our whole-home Wi-Fi service](/services/whole-home-wifi) if you want it solved properly, or read on first.

## Why BT's own hardware struggles in older houses

BT's current router, the Smart Hub 2, comes up often in its own community forum with a specific complaint: weaker Wi-Fi range and a noticeably poor 2.4GHz signal compared with older BT hardware. Several users report the previous Home Hub 5 or original Smart Hub reached upstairs rooms more reliably than the newer one does.

That's a widely reported experience on BT's forum, not a lab-tested fact, and it isn't the whole story either. Wall construction plays a real part too. Solid stone and brick, common across older Buckinghamshire properties, block Wi-Fi signal far more than the modern stud walls a router is typically tested against. One BT forum user described the exact issue: struggling to connect at the far end of a house with 600mm thick stone walls. That's not a fault with the broadband. It's physics meeting an old building.

Put a router built for a standard modern layout into a period Beaconsfield or Amersham cottage with thick internal walls, and the signal was always going to have a harder job.

## Does a BT Wi-Fi enhancer actually fix it?

BT sells a fix for this, and it goes by several names depending on which page you land on: a BT Wi-Fi enhancer, a BT range extender, a BT signal booster. They're all doing the same basic job, whatever the label says. Search reviews for BT extenders or BT wifi boosters and you'll find the same product listed under both terms, often on the same page.

A BT Wi-Fi repeater and a BT Wi-Fi extender work the same way as most BT wifi extenders on the market: picking up the existing signal and rebroadcasting it further into the house. That helps, up to a point. But it needs a reasonably strong signal to begin with, and it adds a relay hop that can reduce speed along the way. In a house where the walls are the real problem, placing a repeater in a slightly-less-weak spot only moves the dead zone, it doesn't remove it.

Search bt booster internet or bt booster for internet and you'll land on the same product either way. Call it a BT extender, a wifi booster BT search away, or a BT range extender: they're all the same relay-based approach, just marketed under different names for different search terms.

## BT whole home Wi-Fi: does BT's own disc system fix it?

BT markets a step up from a single extender: BT whole home Wi-Fi, sold as BT whole home discs. Multiple discs work together to cover the house, similar to how any mesh Wi-Fi system works.

Real-world results are mixed, and the pattern tracks with wall construction. Some users report full coverage through solid brick with no issues. Others, generally in older properties with thicker walls, still report weak spots even with multiple discs installed.

The reason is the same one that applies to any consumer mesh system. Each disc still needs a wireless connection back to the main hub or to the next disc in the chain. That connection has to pass through the same thick walls causing the original problem. Adding more discs helps, but it's still working around the wall rather than avoiding it.

## The actual fix for old Buckinghamshire houses

Skip the relay entirely. Run a physical Ethernet cable to each access point location, so every part of the house gets its own wired connection to the network instead of depending on a wireless hop through a stone or brick wall to get there.

This isn't a criticism of BT specifically. Every consumer extender, booster or mesh disc from any brand runs into the same physical limitation in a thick-walled period property. A wired connection simply doesn't have that problem, because it never needs the signal to travel through the wall wirelessly in the first place.

It costs more upfront than a BT disc off the shelf, mainly in the cabling work rather than the hardware. For a renovation, or a cable run being planned anyway, it's usually a modest addition. For retrofitting into a finished house, cost depends on how accessible the routes are, which is exactly what a site survey is for.

## What this looks like in a real property

We've installed this exact approach in a period home in Beaconsfield Old Town: a central PoE network rack, dedicated Cat6 runs to several access points across the property, and a hardwired connection out to a detached garden studio. Each access point gets a strong local signal from its own cable run, rather than the house depending on a BT hub, a chain of discs, or a single router to cover every room.

## Frequently asked questions

### Why is my BT Smart Hub 2 Wi-Fi worse than my old router?

This is a widely reported experience on BT's own community forum, particularly a weaker 2.4GHz signal compared with older BT hardware like the Home Hub 5. It isn't confirmed as a universal fault, and house construction plays a real part too, since thicker walls make any router's job harder.

### Does a BT Wi-Fi disc fix weak signal in an old house?

Sometimes, but not always. BT's whole home discs still rely on a wireless connection between each disc, which has to pass through the same walls causing the original problem. Results vary depending on wall thickness and disc placement.

### What actually fixes BT Wi-Fi in a period property?

A hardwired connection to each part of the house, using access points connected by Ethernet rather than relying on a wireless relay. This avoids the wall-penetration problem that affects extenders, boosters and mesh discs from any brand, not just BT.

### Is my BT internet actually slow, or is it my Wi-Fi?

Often it's the Wi-Fi, not the broadband connection itself. A quick way to check is running a speed test on a device connected directly to the hub by Ethernet cable, then comparing it with a Wi-Fi speed test in the room where the signal feels weak. A big gap points to the wireless signal, not the underlying broadband speed.

### Can I use my own router instead of BT's Smart Hub for better Wi-Fi?

In many cases, yes, though it depends on your BT package and connection type. A dedicated network setup using separate access points, rather than relying on the ISP-supplied hub for both the internet connection and Wi-Fi coverage, generally gives more control over coverage in an older or larger property.
