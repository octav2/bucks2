### How much does network cabling cost in Bourne End?

### Can you run network cabling to a garden building or riverside outbuilding?

Yes. Where the route and site conditions are suitable, external-rated or armoured network cabling can link a detached building back to the main network so it can support Wi-Fi, wired devices and compatible PoE equipment.

### What's the difference between Cat6 and Cat6a?

Cat6 and Cat6a are both structured Ethernet cabling standards. Cat6a is commonly chosen where 10-gigabit capability over longer compliant runs and additional future headroom are priorities.
